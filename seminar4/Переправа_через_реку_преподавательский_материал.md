# Семинар по ОДУ: задача о переправе через реку
## Преподавательский материал (полный вывод + референсные решения)

---

## 1. Физическая постановка

Река имеет прямолинейные берега, ширина реки — вдоль оси $Ox$. Течение реки
однородно по всей ширине и направлено параллельно оси $Ox$ со скоростью
$v = \mathrm{const}$.

На дальнем берегу, в точке с координатами $(x_0, y_0)$, где $x_0 > 0$,
стартует лодка. Лодка развивает постоянную по модулю скорость относительно
воды $u = \mathrm{const}$ ($u > v$). Рулевой лодки **непрерывно** направляет
нос лодки точно на причал, расположенный в начале координат $(0, 0)$ — то
есть в каждый момент времени вектор скорости лодки относительно воды направлен
из текущей точки положения лодки прямо на точку $(0,0)$.

**Параметры задачи:**
- $x_0, y_0$ — начальные координаты лодки;
- $v$ — скорость течения реки;
- $u$ — собственная скорость лодки относительно воды, $u > v$;
- $k = v/u$ — безразмерное отношение скоростей ($0 < k$, интересен случай $k \gtrless 1$).

---

## 2. Вывод дифференциального уравнения

Скорость лодки относительно берега — векторная сумма скорости течения и
скорости относительно воды. Скорость течения имеет одну компоненту вдоль $Ox$:
$(v, 0)$. Скорость относительно воды направлена по орту на начало координат:
$-\left(\dfrac{x}{r}, \dfrac{y}{r}\right)$, где $r = \sqrt{x^2+y^2}$.

Отсюда:

$$\dot{x} = v - u\frac{x}{r}, \qquad \dot{y} = -u\frac{y}{r}$$

Чтобы избавиться от параметра $t$, делим второе уравнение на первое:

$$\frac{dy}{dx} = \frac{\dot y}{\dot x} = \frac{-uy/r}{v - ux/r} = \frac{-uy}{vr - ux}$$

Вводим $k = v/u$:

$$\boxed{\;\frac{dy}{dx} = \dfrac{-y}{k\sqrt{x^2+y^2} - x}\;}$$

---

## 3. Проверка однородности

$$f(x,y) = \frac{-y}{k\sqrt{x^2+y^2}-x}$$

Подставляем $(\lambda x, \lambda y)$, $\lambda > 0$:

$$f(\lambda x, \lambda y) = \frac{-\lambda y}{k\sqrt{\lambda^2x^2+\lambda^2y^2} - \lambda x} = \frac{-\lambda y}{\lambda\left(k\sqrt{x^2+y^2}-x\right)} = \frac{-y}{k\sqrt{x^2+y^2}-x} = f(x,y)$$

$f$ однородна степени 0 — уравнение однородное, замена $u=y/x$ законна.

---

## 4. Аналитическое решение

Полагаем $y = ux$, тогда $y' = u + xu'$. Так как $x > 0$: $r = x\sqrt{1+u^2}$.

$$u + xu' = \frac{-u}{k\sqrt{1+u^2}-1}$$

$$xu' = -u\left[1 + \frac{1}{k\sqrt{1+u^2}-1}\right] = \frac{-uk\sqrt{1+u^2}}{k\sqrt{1+u^2}-1}$$

Разделяем переменные:

$$\frac{k\sqrt{1+u^2}-1}{uk\sqrt{1+u^2}}\,du = -\frac{dx}{x} \quad\Longrightarrow\quad \left(\frac{1}{u} - \frac{1}{k}\cdot\frac{1}{u\sqrt{1+u^2}}\right)du = -\frac{dx}{x}$$

Первый интеграл элементарен: $\displaystyle\int \frac{du}{u} = \ln|u|$.

Второй — табличный:

$$\int \frac{du}{u\sqrt{1+u^2}} = \ln\left|\frac{u}{1+\sqrt{1+u^2}}\right| \quad\left(\text{эквивалентно } -\operatorname{arcsinh}(1/u)\right)$$

Итого неявное решение:

$$\ln|u| - \frac{1}{k}\ln\left|\frac{u}{1+\sqrt{1+u^2}}\right| = -\ln x + C$$

Возвращая $u=y/x$, $\sqrt{1+u^2}=r/x$, после упрощения (классический результат теории кривых погони):

$$\frac{r+x}{r_0+x_0} = \left(\frac{y}{y_0}\right)^{k}, \qquad r=\sqrt{x^2+y^2},\ \ r_0=\sqrt{x_0^2+y_0^2}$$

**Интерпретация:**
- при $k < 1$ ($v < u$) предел $x \to 0$ достигается при конечном $y \to 0$ — лодка причаливает;
- при $k \geq 1$ ($v \geq u$) — причаливание невозможно, траекторию сносит вдоль течения.

## 5. Референсное решение — Wolfram Mathematica

```mathematica
(* ==================================================== *)
(* Задача о переправе через реку — референсное решение   *)
(* ==================================================== *)

(* --- 1. Параметры (ТОЛЬКО точные числа для символьных операций!) --- *)
kVal = 3/5;      (* k = v/u, ВАЖНО: рациональная дробь, не 0.6 *)
x0 = 10;
y0 = 6;

(* --- 2. Задание ОДУ с символьным k --- *)
ode = y'[x] == -y[x]/(k*Sqrt[x^2 + y[x]^2] - x);

(* --- 3. Проверка однородности f(λx,λy) = f(x,y) --- *)
f[x_, y_, k_] := -y/(k*Sqrt[x^2 + y^2] - x);
homogeneityCheck = Simplify[f[lam*x, lam*y, k] - f[x, y, k], lam > 0]
(* Ожидаемый результат: 0 *)

(* --- 4. Аналитическое решение через DSolve (k остаётся буквой) --- *)
generalSol = DSolve[ode, y[x], x]
(* DSolve может вернуть решение в неявном виде или через
   InverseFunction — это нормально для этого класса уравнений *)

(* --- 5. Численное решение с начальным условием (k подставляем здесь) --- *)
sol = NDSolve[
   {y'[x] == -y[x]/(kVal*Sqrt[x^2 + y[x]^2] - x), y[x0] == y0},
   y, {x, 10^-4, x0}
   ];

(* --- 6. Визуализация траектории --- *)
trajectoryPlot = ParametricPlot[
   {x, y[x] /. sol[[1]]},
   {x, 10^-4, x0},
   PlotStyle -> {Thick, Blue},
   PlotRange -> All,
   AspectRatio -> 1,
   AxesLabel -> {"x", "y"},
   PlotLabel -> "Траектория лодки при переправе (k = " <> ToString[N[kVal]] <> ")",
   Epilog -> {
     {Red, PointSize[0.02], Point[{0, 0}]},
     {Black, Text["Причал", {0.5, 0.7}]},
     {Green, PointSize[0.02], Point[{x0, y0}]},
     {Black, Text["Старт", {x0 - 1, y0 + 0.7}]}
     },
   GridLines -> Automatic,
   ImageSize -> 500
   ]

(* --- 7. Сравнение траекторий при разных k --- *)
kValues = {3/10, 3/5, 9/10, 1, 13/10};
trajectories = Table[
   solK = NDSolve[
     {y'[x] == -y[x]/(kk*Sqrt[x^2 + y[x]^2] - x), y[x0] == y0},
     y, {x, 10^-4, x0}
     ];
   ParametricPlot[
    {x, y[x] /. solK[[1]]},
    {x, 10^-4, x0},
    PlotStyle -> ColorData[97][Position[kValues, kk][[1, 1]]],
    PlotRange -> All
    ],
   {kk, kValues}
   ];

comparisonPlot = Show[
   trajectories,
   Epilog -> {Red, PointSize[0.02], Point[{0, 0}]},
   AxesLabel -> {"x", "y"},
   PlotLabel -> "Зависимость исхода переправы от k = v/u",
   AspectRatio -> 1,

      ToString /@ N[kValues]], Right],
   ImageSize -> 500
   ]
```

**Замечание по `Solve::inex`:** ошибка возникала из-за подстановки `kVal = 0.6`
(machine-precision float) в символьный `DSolve`. Символьные солверы Mathematica
требуют exact-арифметику; `0.6` — сигнал «дальше не думай символьно». Решение:
держать `k` буквой в `DSolve`, а числовое (точное рациональное, `3/5`, не `0.6`)
значение подставлять только на этапе `NDSolve`/`Plot`.

## 6. Референсное решение — Python (SymPy + SciPy)

```python
import sympy as sp
import numpy as np
import matplotlib.pyplot as plt
from scipy.integrate import solve_ivp

# --- Символьная часть: проверка однородности и dsolve ---
x, y, k = sp.symbols('x y k', positive=True)
Y = sp.Function('y')

r = sp.sqrt(x**2 + Y(x)**2)
ode = sp.Eq(Y(x).diff(x), -Y(x) / (k*r - x))

# Аналитическое решение через dsolve (hint для однородных уравнений)
sol = sp.dsolve(ode, Y(x), hint='1st_homogeneous_coeff_best')
print(sol)

# Проверка подстановкой
check = sp.simplify(ode.lhs.subs(Y(x), sol.rhs).doit() - ode.rhs.subs(Y(x), sol.rhs))
print("Невязка после simplify:", check)

# --- Численная часть: траектория и фазовый портрет ---
def rhs(x, y, k_val):
    r = np.sqrt(x**2 + y**2)
    return -y / (k_val*r - x)

x0, y0 = 10.0, 6.0
k_val = 0.6

sol_num = solve_ivp(lambda x, y: rhs(x, y, k_val), [x0, 1e-4], [y0],
                     dense_output=True, rtol=1e-9, atol=1e-9)

xs = np.linspace(x0, sol_num.t[-1], 400)
ys = sol_num.sol(xs)[0]

plt.figure(figsize=(6, 6))
plt.plot(xs, ys, lw=2, label=f'k={k_val}')
plt.plot(0, 0, 'r*', markersize=15, label='Причал')
plt.plot(x0, y0, 'go', label='Старт')
plt.xlabel('x'); plt.ylabel('y')
plt.title('Траектория лодки при переправе')
plt.legend(); plt.grid(True); plt.axis('equal')
plt.show()

# --- Сравнение траекторий при разных k ---
plt.figure(figsize=(6, 6))
for kv in [0.3, 0.6, 0.9, 1.0, 1.3]:
    s = solve_ivp(lambda x, y: rhs(x, y, kv), [x0, 1e-4], [y0],
                   dense_output=True, rtol=1e-9, atol=1e-9, max_step=0.05)
    xs = np.linspace(x0, s.t[-1], 400)
    plt.plot(xs, s.sol(xs)[0], label=f'k={kv}')
plt.plot(0, 0, 'r*', markersize=15, label='Причал')
plt.xlabel('x'); plt.ylabel('y')
plt.legend(); plt.grid(True); plt.axis('equal')
plt.title('Влияние k=v/u на исход переправы')
plt.show()
```

**Замечание по границе интегрирования:** нижний предел взят `1e-4`, а не `0` —
в точке причала при $k<1$, $y\to 0$ знаменатель $k\sqrt{x^2+y^2}-x \to 0$, и
решатель может застрять на особенности. Для целей демонстрации это не критично.
